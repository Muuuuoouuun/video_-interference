# 제품 판단 기준

사용자 결정 · 2026년 10월 14일

우선순위는 **1. 본질 → 2. 편의성 → 3. 사용성**이다. 첫 사용자는 혼자 영상을 만드는 사람이며, 지금은 데스크톱을 기준으로 만든다.

## 현재 프로토타입의 초점

2026년 10월 14일 사용자는 영상 파일 자체의 전달보다 **타임의 내용–피드백 전달**을 먼저 완성하도록 정했다. 이 단계의 기본 흐름은 `영상 확인 → 시점/구간 → 장면 내용·그림·피드백 → 저장·보완 → 전달 자료`다. 원본·편집 영상 파일을 전달 묶음에 넣지 않는다. 해석·승인·렌더는 부가 편집 기능으로 유지하며 이 프로토타입의 선행 조건으로 삼지 않는다. [구체적인 화면·정보·검수 기준](피드백프로토타입.md)을 우선 적용한다. 아래 AI 편집 원칙은 이후 제품 전체의 방향으로 보존한다.

## 1. 본질

장면 위에 수정 의도를 남기고, AI가 이해한 내용을 확인한 뒤, 해당 장면의 실제 결과로 이어져야 한다. 제품의 중심 흐름은 `영상 열기 → 시점·구간 지정 → 요청 저장 → 해석·보완 → 승인 → 새 버전 검수`다.

- 요청의 문장, 작성 버전, 범위, 그림을 그린 프레임과 첨부 용도를 함께 보존한다.
- 즉시 해석을 강제하지 않는다. AI 연결이나 해석에 실패해도 요청은 저장되어야 한다.
- 추가 지시는 같은 요청의 이력으로 보관한다. 원문과 기존 결과를 덮어쓰지 않는다.
- 뜻이 충돌하면 확인할 질문을 만든다. 승인한 내용과 실행한 내용이 달라지지 않아야 한다.
- 그림은 기본적으로 위치를 설명하는 메모다. 영상에 넣는 행위는 명시적인 요청과 승인으로 정한다.
- 컷·배속 뒤에도 같은 원본 장면을 찾아야 한다. 삭제된 장면에 대한 요청을 다른 장면으로 옮기지 않는다.

판단 질문: **원하는 장면과 원하는 변경이 정확히 연결되어 결과까지 이어지는가?**

## 2. 편의성

사용자가 같은 맥락을 반복해서 설명하지 않게 한다. 영상에서 정한 시점·구간·그림과 자료를 요청에 자동으로 묶는다.

- 먼저 요청을 모아두고 나중에 한 번에 해석·실행할 수 있게 한다.
- 보완이 필요하면 같은 카드에서 지시를 덧붙인다. 영상과 자료를 다시 등록하게 하지 않는다.
- 저장된 요청을 살펴봐도 작성 중인 초안은 유지한다. 새 요청에 그림을 가져갈 때는 복사를 명시한다.
- 결과가 마음에 들지 않으면 이전 버전으로 돌아가 이어서 작업할 수 있게 한다.
- 내보내기·저장·복구가 일상적인 작업 흐름 안에 있어야 한다.

판단 질문: **사용자가 반복 입력하거나 외워야 하는 맥락을 줄이는가?**

## 3. 사용성

지금 보고 있는 것, 저장한 것, 실행할 것과 다음 행동이 분명해야 한다.

- 저장된 요청을 보는 상태와 새 요청을 작성하는 상태를 화면에서 구분한다.
- 요청 저장, 해석 대기, 보완 필요, 승인, 렌더와 결과 버전을 구별한다.
- 추가 지시를 저장하면 기존 승인이 해제되는 이유를 저장 전에 보여준다.
- 보기 배속과 출력 배속, 참고 이미지와 삽입 이미지, 위치 메모와 출력 그래픽을 구별한다.
- 도형은 선택·이동·크기 조절·되돌리기가 일관되게 동작해야 한다. 화면에서 즉시 반응하고 결과 좌표도 일치해야 한다.
- 오류는 해결할 위치와 다음 행동을 알려야 한다. 실패한 입력과 저장한 요청을 잃지 않는다.

판단 질문: **현재 상태와 다음 행동을 별도 설명 없이 이해할 수 있는가?**

## 개발과 검수 순서

요청의 장면·의도 보존과 실행 정확도를 먼저 해결한다. 다음으로 저장된 요청의 보완·재해석, 초안 보존과 복구를 완성한다. 그 흐름 위에서 화면·키보드·그림 조작을 검수한다. 실제 의미 해석과 음성 전사는 핵심 흐름에 연결하되, 공급자 설정을 요청 저장의 선행 조건으로 만들지 않는다.

필수 검수 사례:

1. 그림과 구간을 지정한 뒤 요청만 저장한다. 나중에 추가 지시로 배속을 정하고 해석·승인한다. 원문과 앵커가 유지되고 결과가 같은 장면에 적용된다.
2. 새 요청을 작성하다가 기존 카드를 확인한다. 초안으로 돌아가면 문장·첨부·그림·범위가 유지된다. 기존 그림을 바꾸려면 명시적으로 새 요청에 복사한다.
3. 배속과 컷을 실행한 뒤 요청 위치, 자막·그림 노출, 음성 위치와 결과 길이를 확인한다. 취소·종료 후에도 원본과 승인 상태를 복구한다.

화면 조작·입력 지연은 실제 데스크톱 브라우저에서 검수한다. 엔진 테스트나 렌더 시간은 이 검수를 대신하지 않는다. 전체 완성 조건과 증거의 범위는 [완료감사](완료감사.md)에 유지한다.
