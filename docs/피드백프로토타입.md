# 시간별 영상 피드백 프로토타입

2026년 10월 14일 사용자 결정: **“프로토타입은 영상을 그대로 전달하는 게 아니라, 타임의 내용–피드백을 전달하는 것에 포커스.”**

## 목적

영상을 보면서 **언제, 어떤 장면에서, 무엇을 바꾸길 원하는지** 기록하고, 다른 AI나 편집자가 바로 검토할 수 있는 자료로 정리한다. 영상 파일은 로컬에서 장면을 확인하는 데 사용한다. 전달물은 시간별 피드백 문서, 장면 스틸, 그림 표시와 참고 자료다.

첫 사용자는 혼자 영상을 만드는 사람이다. 데스크톱에서 편하게 표시하고 기록하는 흐름을 우선한다. 기본 앱의 저장·내보내기는 로컬에서 처리한다. 사용자의 후속 지시에 따라 필요한 AI 해석 테스트에는 Gemini를 사용하며, 선택한 자료를 명시적으로 호출하는 [별도 테스트](Gemini테스트.md)로 진행한다.

## 기본 흐름

1. **영상 열기:** 첫 화면에서 영상 파일 하나를 선택하거나 끌어 놓는다. 실제 장면 썸네일로 찾고 재생·일시 정지한다.
2. **시점 지정:** 기본은 현재 시점이다. 기존 피드백을 보다가 플레이어의 `C` 또는 ‘현재 시점에 피드백’을 누르면 실제 재생 위치에서 새로 작성한다. 작성 중인 초안이 있으면 기존 시점·구간·그림 기록으로 복귀한다. 저장 카드의 ‘이 구간에 새 피드백’은 해당 구간을 재사용하는 별도 행동이다. 길이가 있는 피드백은 ‘구간 지정’ 또는 I/O로 범위를 만든다. 앱을 열 때 예시 구간이나 첫 댓글을 자동 선택하지 않는다. 지정한 구간은 × 또는 ‘구간 해제’로 없애고 현재 시점으로 돌아간다. 구간이 있을 때만 IN/OUT·보기용 구간 반복을 표시한다.
3. **장면과 피드백 기록:** 입력창에 들어가면 재생을 멈추고 현재 시각을 읽는다. 기본 작성창에는 시간과 피드백 입력·저장만 둔다. 장면 설명·메모·이미지·음성은 닫힌 ‘추가 옵션’에서 선택한다. 장면 설명은 실제 보이는 내용을 직접 적는다. 선택한 첨부와 녹음 종료·재시도는 옵션을 접어도 계속 보인다.
4. **저장·수정·보완:** 해석을 기다리지 않고 저장한다. 카드의 수정 버튼으로 장면 내용과 피드백을 고치고, 추가 지시로 보완 기록을 남긴다. 다른 카드나 필터로 옮겨도 수정 초안을 유지한다. 삭제는 휴지통으로 이동하며 되돌리기와 휴지통에서 복구할 수 있다.
5. **피드백 내보내기:** 저장한 내용을 한 번에 모아 ZIP으로 받거나, 문서의 텍스트를 복사한다.

장면 내용만 기록하고 싶으면 메모로 저장한다. 음성 내용은 자동 전사하지 않는다. 전달 묶음에는 영상 트랙이 없는 오디오 파일로 넣는다. 그림은 해당 장면을 설명하는 표시다.

## 한 항목의 정보 구조

| 항목 | 의미 |
|---|---|
| 작성 영상·시점 | 피드백을 남길 때 실제로 보고 있던 버전과 타임코드 |
| 적용 구간 | 한 시점 또는 IN–OUT 범위. 내부 좌표는 30fps, 끝 프레임 제외 |
| 장면 내용 | 사용자가 직접 작성한 장면 설명. 비워 두면 미작성으로 표시 |
| 피드백 | 원문과 이후 보완 기록 |
| 장면 스틸 | 기준 장면·구간·그림을 남긴 시점의 실제 이미지 |
| 그림 표시 | 원본 스틸과 별도로 그림이 표시된 스틸, 정규화 좌표 |
| 참고 자료 | 이미지의 용도, 녹음 내용 등 |
| 현재 버전 대응 | 컷·배속 후 살아 있는 구간, 부분 생존 또는 삭제 상태 |

예:

> 작성 v1 · 00:12.400–00:15.000<br>
> **장면 내용:** 제품을 들어 보이며 이름을 설명하는 장면<br>
> **피드백:** 제품 이름 자막을 아래에 넣고, 동그라미 친 부분을 더 크게 보여 주세요.<br>
> **자료:** 해당 스틸, 원이 표시된 스틸, 참고 이미지

AI가 장면을 자동으로 이해했다는 설명을 붙이지 않는다. 사용자의 관찰, 요청, 이미지 증거를 구분한다. 편집으로 사라진 구간도 원래 작성 시점과 스틸을 유지하며 다른 장면에 자동으로 붙이지 않는다.

## 전달물

- **feedback.md:** 사람이 읽고 복사할 수 있는 시간별 문서. 이미지 경로는 ZIP 내부를 기준으로 한다.
- **manifest.json:** AI나 다른 도구가 읽을 수 있는 시점·구간·좌표·피드백 구조.
- **scenes / annotations / attachments:** 실제 장면, 그림이 표시된 스틸, 참고 자료. 구체적인 상대 경로는 manifest에 기록한다.
- **feedback.zip:** 위 파일을 함께 담는 이동 가능한 묶음. 원본·편집 영상 파일을 포함하지 않는다.

‘텍스트 복사’는 문구를 클립보드에 복사한다. 스틸과 첨부가 필요한 전달에는 ZIP을 사용한다. 버튼을 눌러 자료를 준비해도 외부 서비스로 자동 전송하지 않는다.

## 화면 우선순위

첨부 HTML의 **통합안 · 메인 리뷰 화면 / 사이드바 1 · 큐 리스트형**을 기준으로 밝은 회색 바탕, 흰 패널, 파란 강조색을 적용한다. 영상, 현재 시각, 우측 댓글 목록과 작성창이 중심이다. 프로젝트 패널은 기본으로 접고 댓글 패널은 열어 둔다. 양쪽 패널을 접거나 펼칠 수 있으며 작성 내용과 첨부는 유지된다. C 또는 플레이어의 피드백 작성 버튼은 댓글 패널을 다시 열고 입력창으로 이동한다.

기본 작성창은 저장된 댓글을 검토하는 동안에도 보인다. 입력을 시작하면 검토를 끝내고 현재 시점에서 작성하거나 기존 초안으로 돌아간다. 저장 댓글의 구간·그림 재사용은 별도 접기 영역에 둔다. 타임라인의 번호 마커로 해당 댓글과 장면을 연다. 그림·도형 도구는 바로 사용할 수 있고, 색·굵기·채움은 기본으로 닫힌 ‘그림 스타일’에서 변경한다. 가장 눈에 띄는 상단 행동은 **피드백 내보내기**다.

명령 해석·승인·영상 렌더·적용된 레이어 수정은 상단 ‘더 보기 → 편집 기능’을 열었을 때 사용할 수 있는 부가 기능으로 둔다. 기본 피드백을 저장하거나 전달하는 데 이 과정이 필요하지 않다. 기존 구현과 원본·버전 데이터는 유지한다.

## 이번 단계의 검수 조건

1. 시점 하나에 빠르게 피드백을 저장하고, 범위가 필요할 때 구간으로 전환할 수 있다.
2. 시점·범위·그림·장면 설명·피드백·첨부가 함께 저장된다. 저장 실패와 카드 검토에서 초안이 사라지지 않는다.
3. PC 영상으로 내보낸 스틸이 해당 작성 시점과 일치하고 그림 위치도 맞는다.
4. 컷·배속된 버전과 삭제된 장면의 작성 위치·현재 대응을 혼동하지 않는다.
5. 압축을 풀어 MD·JSON·이미지·첨부의 연결을 확인할 수 있고 영상 파일이 들어 있지 않다.
6. 그리기·이동·크기 조절·되돌리기·구간 반복을 데스크톱 화면에서 검수한다. 순수 계산과 native 렌더 검사를 실제 조작 검증으로 대체하지 않는다.

실제 AI 의미 해석, 자동 음성 전사, 자동 편집 결과 생성, 원본 PTS 정밀 앵커, 협업과 모바일은 제품 전체의 후속 요구사항으로 보존한다. 이번 사용자 결정에 따라 먼저 위 피드백 전달 흐름을 완성한다. 구현·검증 결과와 남은 조건은 [완료감사](완료감사.md)에 기록한다.

## 데스크톱 피드백 편의 기능

- 카드의 **수정** 또는 본문 더블클릭으로 직접 편집한다. 수정 이력은 로컬에 남고 시간·그림·첨부는 유지된다. 미적용 편집 명령은 다시 해석·승인해야 하며, 이미 렌더에 적용된 피드백은 새 피드백으로 변경 의도를 남긴다.
- 목록에서 피드백·장면 내용·추가 지시·첨부 파일명을 검색하고 **영상 시간순 / 최근 작성순**으로 정렬한다. 영상 시간순은 현재 버전에서 살아 있는 구간을 기준으로 하며 삭제·위치 불명 항목은 뒤에 둔다. 번호는 타임라인과 같게 유지한다. 검색·정렬로 재생 위치나 초안을 바꾸지 않는다. 타임라인에서 항목을 선택하거나 저장·이어쓰기를 하면 검색과 분류를 풀어 해당 카드를 보여 준다.
- **삭제**한 항목은 목록과 새 전달 묶음에서 제외한다. 알림의 **되돌리기** 또는 왼쪽 **휴지통**에서 복구한다. 앱을 다시 열어도 휴지통을 유지하며 이전 렌더 결과는 변경하지 않는다.
- 첨부 이미지는 작성창·저장 카드에서 썸네일과 용도를 확인하고, 클릭하면 크게 본다. 여러 장 선택·끌어 놓기·붙여넣기를 지원한다. 한 피드백당 이미지 10장까지이며 음성은 별도로 저장한다. 남은 수량보다 많은 파일을 선택하면 해당 묶음 전체를 업로드 전에 거절하고 추가 가능한 수량을 안내한다. 이미지 업로드 전에 재생을 멈추며, 음성 첨부는 재생할 수 있다.
- 입력 중인 내용이 있으면 내보내기·버전 변경·렌더를 제한한다. 편집 내용을 저장하거나 취소한 뒤 진행한다.
- 저장 카드에서는 이미지 4장부터 보여 주고 나머지는 펼쳐 본다. 음성은 이미지 접힘과 관계없이 표시한다. 확대 창은 이전·다음 버튼, 좌우 방향키와 썸네일로 이미지를 바꿀 수 있다. 한 시점의 피드백은 타임코드 하나로 표시하고, 다른 버전의 피드백은 작성 시점과 현재 대응을 함께 표시한다.

| 키 | 동작 |
|---|---|
| C | 현재 시점에 새 피드백 · 작성 중인 초안으로 복귀 |
| F2 | 포커스된 카드 우선, 없으면 선택한 피드백 수정 |
| Shift + Delete | 포커스된 카드 우선, 없으면 선택한 피드백을 휴지통으로 이동 |
| ⌘ / Ctrl + Enter | 피드백·수정·추가 지시 저장 |
| Alt + ↑ / ↓ | 목록에 포커스가 있을 때 이전·다음 피드백 |
| Esc | 수정 취소, 이미지 미리보기·도움말 닫기 |
| ? 또는 ⌘ / Ctrl + / | 단축키 도움말 |
| ← / → (이미지 확대 창) | 이전 / 다음 이미지 |

문자 입력과 한글 조합 중에는 영상·그림 단축키를 실행하지 않는다. 그림 영역의 Delete는 선택한 그림을 삭제하며 피드백 삭제와 구분한다.

첨부 HTML 시안의 시간→본문 계층과 목록 이동 흐름을 참고했다. 기존 다크·민트 색상 체계를 유지하고, 썸네일과 확대 미리보기는 실제 첨부 확인을 위해 추가했다. 모바일은 이번 작업 범위에서 제외한다.

## 이번 화면 개편 검증 범위

시점·구간 생성은 순수 함수 검사, 구간 표시·해제 버튼·댓글 마커의 정적 출력은 실제 React 컴포넌트 검사로 확인한다. 전체 API·미디어 회귀와 프로덕션 빌드를 함께 확인한다. 이 검사는 실제 화면의 배치, 키보드 포커스, 드래그 조작을 대체하지 않는다. 현재 자동 브라우저 도구의 사이트 권한 차단으로 변경 화면의 직접 조작 검수는 미완료다.
