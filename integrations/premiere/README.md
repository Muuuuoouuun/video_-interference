# Premiere 연동 프로토타입 0.2

영상·스틸 없이 **댓글, 시간, 도형 좌표, 투명 PNG**를 전달합니다. 패널에서 댓글을 마커로 반영하고, 오버레이를 Premiere 영상 위 전용 트랙에 배치합니다. AI 호출이나 네트워크 연결은 없습니다.

## 설치

Adobe Premiere **25.6 이상**, UXP Developer Tool **2.2 이상**이 필요합니다.

1. Premiere 설정 → Plugins → Enable developer mode를 켜고 Premiere를 다시 시작합니다.
2. 앱의 **더 보기 → Premiere 연동 → 처음 연결하기 → 개발용 패널 ZIP 받기**로 패널을 받아 압축을 풉니다.
3. UXP Developer Tool에서 Add Plugin으로 패널 폴더의 `manifest.json`을 선택하고 Load를 누릅니다. 개발 중에는 이 소스 폴더를 직접 선택해도 됩니다.
4. Premiere의 Window → UXP Plugins → Video Interference를 엽니다.

개발용 패널이며 서명·Marketplace 배포 패키지는 아닙니다. **실제 Premiere 호스트에서 로드·배치 검증은 아직 필요합니다.**

## 영상 위 오버레이 적용

1. 앱에서 댓글과 그림을 저장하고 **더 보기 → Premiere 연동 → 영상 위 오버레이 묶음**을 받습니다.
2. ZIP을 Premiere 프로젝트와 함께 보관할 폴더에 압축 해제합니다. 패널의 **오버레이 묶음 폴더 열기**에서 `premiere-feedback.json`이 있는 폴더를 선택합니다.
3. 기준 영상과 **같은 편집 버전, 같은 해상도, 정사각형 픽셀**인 시퀀스를 엽니다. 영상 위에 비어 있는 영상 트랙 하나를 준비합니다. 트랙 표시를 켜고 잠금을 해제합니다.
4. 영상이 시퀀스 처음에서 시작하면 시작 위치를 `0`초로 둡니다. 앞에 인트로가 있다면 영상 시작 위치를 **시퀀스 처음부터의 초**로 입력합니다. 표시 타임코드가 `01:00:00:00`이어도 시퀀스 처음은 `0`초입니다.
5. **현재 시퀀스에 연결 → 파일·배치 확인**을 누릅니다. 대상 트랙, 구간 수, 시퀀스 기준 시간을 확인합니다.
6. **V…에 오버레이 적용**을 누르면 투명 PNG 클립들이 해당 트랙에 배치됩니다. Premiere 재생에 따라 해당 구간에서 보이고, Program Monitor와 출력 영상에도 포함됩니다.
7. 댓글 마커는 **마커 갱신**으로 별도 반영합니다. 댓글·그림의 시간 버튼으로 해당 위치에 이동할 수 있습니다.

적용 후 PNG 폴더를 이동하거나 삭제하면 오프라인 미디어가 됩니다. PNG를 영상과 함께 Premiere 프로젝트에 보관하세요. 원본 영상은 묶음에 포함되지 않습니다.

## 표시 규칙

- 댓글 IN–OUT은 시작 포함, 끝 제외입니다. 구간 없는 시점 댓글은 앱 기준 한 프레임입니다.
- 첫 그림은 댓글 IN부터 표시합니다. 같은 댓글에 여러 시점의 그림이 있으면 다음 그림 시점에서 교체하고, 마지막 그림은 댓글 OUT까지 표시합니다.
- 서로 다른 댓글이 겹치는 시간은 투명 캔버스 한 장에 합칩니다. 앱의 내보내기 댓글 순서대로 쌓이며 뒤의 댓글이 위에 옵니다. 한 트랙에서 중첩 그림을 보여줍니다.
- 컷·배속은 원래 작성 버전의 구간을 현재 버전으로 변환합니다. 삭제된 그림 시점 또는 댓글 구간 밖의 그림은 원래 좌표·PNG를 보존하되 트랙에 배치하지 않습니다. 제외 수를 앱과 패널에서 표시합니다.
- 영상 전체 크기의 PNG와 정사각형 픽셀을 사용하여 기본 중앙 위치·100% 배율에서 좌표를 맞춥니다. 펜·사각형·타원·선·화살표·텍스트, 색·두께·투명도를 보존합니다.
- **Premiere의 편집 가능한 벡터 도형으로 변환하지 않습니다.** 도형 수정은 앱에서 하고 새로 내보내 적용합니다. 참고 이미지·음성·기존 편집 효과·MOGRT는 이 내보내기에 포함하지 않습니다.

## 다시 적용 / 삭제 / 실행 취소

수정한 묶음을 새 폴더에 풀어 다시 열거나, 같은 폴더를 갱신하고 **다시 읽기**를 누릅니다. 시퀀스 연결과 배치를 다시 확인합니다. 해당 프로젝트·버전의 전용 오버레이 트랙만 교체하고 영상·오디오는 밀지 않습니다. 같은 파일 경로는 프로젝트 미디어를 재사용합니다. 새 묶음 경로 또는 변경된 PNG는 새 미디어 항목으로 가져옵니다. 과거 미디어 항목과 파일은 자동 삭제하지 않습니다.

같은 버전의 그림을 모두 삭제한 묶음을 적용하면 해당 연동 오버레이만 지웁니다. 비어 있는 댓글 자료의 **마커 갱신**은 해당 버전의 마커만 지웁니다. 오버레이 트랙 교체와 마커 갱신은 각각 한 번의 실행 취소로 되돌릴 수 있습니다. PNG 가져오기·투명도/길이 준비는 별도 단계이며 실행 취소 기록도 별도입니다.

다른 클립이나 전환 효과가 섞인 트랙, 여러 트랙으로 분산된 연동 오버레이, 다른 영상 트랙 아래에 놓인 연동 트랙은 자동으로 정리하지 않습니다. 전용 트랙으로 모아 다시 적용하세요. 동일 버전의 연동 PNG 파일 이름은 식별에 쓰므로 바꾸지 마세요. 트랙에서 직접 수정한 해당 버전의 배치·효과는 다음 적용 시 교체됩니다.

## 시간과 버전 정합성

앱 내부 시간은 30fps입니다. 시퀀스 fps가 달라도 초를 실제 시퀀스 프레임 경계로 변환하여 누적 드리프트를 피합니다. 최대 반 프레임의 양자화 차이가 생길 수 있습니다. 낮은 fps에서 한 프레임 미만으로 사라지는 구간은 적용을 중단하므로 앱에서 표시 구간을 늘려 주세요.

연결한 프로젝트·시퀀스 ID, 길이, fps, 해상도를 확인합니다. 적용 전에 트랙 배치와 PNG 크기·알파·SHA256을 다시 확인합니다. 파일 누락·변경 시 트랙 수정 전에 중단합니다. **동일 길이를 유지한 편집이나 영상 내용 변경까지 자동 감지하지는 못합니다.** 컷·배속·순서를 변경했다면 새 기준 영상으로 다시 검토하세요.

파일 기반 단방향 갱신입니다. 실시간 양방향 동기화, Program Monitor에서 직접 그리기, Premiere 개별 도형 편집은 범위 밖입니다. 프로젝트당 최대 300개 댓글·300개 그림 묶음·600개 합성 구간, 타임라인 PNG 총 128MB를 지원합니다.

## 검증

`node --test tests/premiere-handoff.test.mjs tests/premiere-overlays.test.mjs`

영상 파일 없이 내보내기, ZIP 내용, 실제 PNG 좌표·알파·겹침 합성, 컷·배속 구간 변환, 24/29.97fps 시간 변환, 호스트 모형의 중복 방지·실행 취소·기존 트랙 보존, 파일 검증을 검사합니다. 별도 합성 영상에 대한 native FFmpeg 검사로 IN 직전/시작/OUT 직전/종료 프레임의 픽셀도 확인합니다. 이 검사는 실제 Premiere 로드·배치 검증을 대신하지 않습니다.

실제 호스트 확인 시: 샘플 시퀀스에 빈 V2 준비 → 적용 → IN/OUT과 모서리·중앙 위치 확인 → 재적용 후 클립 수 확인 → 실행 취소 → 프로젝트 저장·다시 열어 PNG 연결 확인. Premiere의 영상 크기·기본 배치 설정이 특수하면 위치·배율을 확인하세요.
