영상과 첨부 이미지에 테마 색을 덮지 않는다. 사용자가 그린 선·도형의 색도 유지한다. 색상과 타이포그래피는 `apps/web/src/theme.css`, 화면 그리드와 패널 접힘은 App과 기존 레이아웃 CSS에서 담당한다. 테마 파일을 모든 기본 CSS 다음에 불러온다.

현재 확인 범위는 첨부 HTML에서 추출한 실제 스타일 값과 구현 소스의 대응이다. 저장된 브라우저 접근 제한으로 최신 화면의 시각 검수는 아직 완료하지 못했다. 실제 영상 시간·진행 상태를 사용하며, 작업 완료 상태나 AI 결과를 디자인용으로 꾸며 넣지 않는다.

## 표기·마커 정리 · 2026-10-15

마커는 필름스트립 위의 별도 행에 둔다. 28px 클릭 영역의 번호 배지에 중립색 테두리를 사용하고, 선택 상태에만 옅은 파랑과 하단 선을 적용한다. 양 끝의 배지는 작업 영역 안에 유지하되 연결선은 실제 시간 위치를 가리킨다. 초점 테두리는 안쪽에 표시한다.

서로 겹치는 마커는 `번호 +추가 개수`로 묶는다. 누르면 각 번호·정확한 시점/구간·댓글 내용을 선택할 수 있고, 방향키와 Enter로 이동·선택하며 Escape로 닫는다. 묶음은 가용 폭에 따라 계산하고 저장된 프레임과 댓글 번호는 바꾸지 않는다. 재생 시간 변화만으로 묶음을 다시 계산하지 않는다.

댓글 번호는 22px 기준의 테두리 배지로 맞춘다. 시점에는 시계, 구간에는 대괄호 아이콘을 쓰며, 고정폭 시간을 먼저 읽고 현재 버전은 보조로 표시한다. 작성창의 검정 시간 배지는 중립 면으로 바꾼다. 플레이어·마커·댓글·작성창은 같은 소수 둘째 자리 시간 포맷을 사용한다.

이 변경의 검증은 배치 계산·SSR 마크업·회귀 테스트와 빌드에 한정한다. 실제 브라우저에서의 시각·키보드·포인터 검수는 접근 제한이 해소된 뒤 확인해야 한다.

댓글 카드의 수정·삭제는 오른쪽 위에 28px 아이콘 버튼으로 배치한다. 평소에는 약한 회색으로 보이고 카드 hover·키보드 focus에서 선명해진다. 버튼 자리는 항상 확보해 시간 표기를 가리거나 hover 때 내용이 밀리지 않게 한다. 삭제의 붉은 강조는 해당 버튼 hover에만 사용한다. 아이콘에는 이름·도움말·단축키 정보를 유지한다.

추가 지시는 활성화할 때 입력창으로 포커스를 옮기고, 수정·추가 저장 또는 취소 후에는 원래 버튼으로 돌린다. 삭제한 카드에 포커스가 있었다면 다음 카드, 이전 카드, 검색창 순으로 이어간다. 이 포커스 이동 자체로 다른 영상 시점을 선택하지 않는다. 카드에 연결된 첨부 목록과 갤러리는 입력 중 반복 계산·렌더링을 줄인다.

## 시간축·구간 입력 후속 정리

17:38 사용자 첨부 화면을 기준으로 마커·재생 위치·구간 경계의 구별을 강화한다. 댓글 마커는 별도 행, 재생 위치는 짙은 중립색 머리와 밝은 세로선, 구간은 얇은 회청색 경계와 약한 채움으로 표현한다. 필름스트립은 64px 높이와 6px 모서리를 쓴다. 구간 핸들의 클릭 폭은 22px, 실제 경계선은 2px이다. 핸들은 잡은 위치부터의 이동량으로 조절하여 누르는 순간 기존 구간이 움직이지 않게 한다.

하단은 **시작 → 끝 · 길이 → 해제** 순서다. 저장된 댓글의 구간은 흐린 비활성 입력 대신 읽기 전용 값과 정적인 경계로 표시한다. 편집 입력은 초·분:초·시:분:초를 지원하고, Enter 또는 입력창을 벗어날 때 적용한다. 빈 값과 잘못된 값은 기존 시간을 유지하며 Escape는 타이핑 중인 초안을 취소한다. ↑↓는 즉시 한 프레임, Shift와 함께 누르면 한 초씩 조절한다. 끝 경계는 해당 프레임을 포함하지 않으며 영상의 전체 길이까지 지정할 수 있다.

## 펼쳐 보는 구간·시안

구간 입력 아래에 **구간·시안 펼치기**를 둔다. 기본은 접힘이며, 펼치면 저장된 댓글·구간, 그림·도형, 시안·이미지, 음성의 위치를 각각 시간축에 표시한다. 자료가 있는 종류만 표시하고 시간 눈금과 댓글 번호를 함께 제공한다. 시안은 댓글에 실제 연결된 참고·삽입 이미지이며 자동 생성 결과를 뜻하지 않는다.

겹치는 항목은 다른 행에 배치한다. 짧은 구간과 한 프레임 그림도 28px 클릭 폭을 확보하되, 아래의 얇은 선은 실제 시간 위치와 길이를 나타낸다. 선택한 항목만 옅은 파랑으로 표시한다. 같은 행의 좌우 방향키·Home·End는 초점을 옮기며 Enter로 선택한다.

항목을 누르면 해당 시점으로 이동하고 오른쪽 댓글 패널을 연다. 상세 영역에서 정확한 시간·장면·피드백을 확인하고 이미지 항목은 썸네일·확대 보기, 음성 항목은 재생으로 이어진다. 그림은 댓글 시작점이 아니라 그림이 저장된 실제 프레임으로 이동한다. 편집으로 분리된 구간과 배속 변경은 현재 버전의 위치로 환산하며, 삭제되거나 위치를 확인할 수 없는 댓글은 별도 접힌 목록에서 확인한다.

상세 트랙과 첨부 미디어는 펼칠 때만 마운트한다. 시간축 모델과 겹침 배치는 메모화하여 영상 재생 시간만 바뀔 때 반복 계산하지 않는다. 검증은 모델 테스트·SSR 계약·빌드이며 실제 화면 조작 검수와 구분한다.

## 패널 너비와 조절 성능

데스크톱에서 펼친 프로젝트·댓글 패널의 안쪽 경계를 드래그해 너비를 조절한다. 중립 회색 손잡이와 10px 클릭 영역을 사용하고, hover·키보드 초점·조절 중에만 경계선을 강조한다. 프로젝트는 160–320px, 댓글은 320–640px 범위이며 가용 폭에 맞춰 영상 영역 440px를 우선 확보한다. 창이 더 좁으면 패널 최소 폭을 유지한다.

너비 설정은 현재 브라우저에 저장한다. 접기·펼치기로 작성 내용·영상·스크롤 상태를 초기화하지 않으며, 좁은 창에 맞춘 임시 축소는 저장한 너비를 덮어쓰지 않는다. 더블클릭 또는 Enter는 해당 패널의 기본 너비(프로젝트 180px, 댓글 380px)를 복원한다. 경계에 초점이 있을 때 좌우 방향키는 10px, Shift와 함께 누르면 40px, Home·End는 최소·최대 너비로 이동한다. Esc·포인터 취소·창 전환·창 크기 변경은 진행 중인 드래그를 취소한다.

드래그 이동은 화면 프레임당 한 번 처리하며 너비 상태를 레이아웃 컴포넌트 안에 둔다. 영상·댓글 트리의 불필요한 재렌더를 피하고, 저장소 쓰기는 드래그 종료·키 조절 완료 시에만 한다. 영상 좌표가 같으면 상태를 재사용하고, 시간축은 ResizeObserver의 측정값을 사용한다. 필름스트립은 패널 조절 때문에 다시 생성하거나 불러오지 않는다. 실제 조작 속도 측정과 브라우저 검수는 도구 접근 제한으로 아직 수행하지 못했다.

## 시간축 탐색 영역 확대

18:31 사용자 화면의 시간 눈금과 마커 주변 빈 공간을 필름스트립과 같은 탐색 영역으로 묶는다. 클릭하면 해당 위치로 이동하고, 누른 채 드래그하면 이어서 탐색한다. 마커 번호·묶음 선택·구간 손잡이·팝업·장면 미리보기 재시도 버튼은 각자의 기존 동작을 유지한다. 구간 입력과 펼친 상세 트랙은 이 탐색 영역에 포함하지 않는다.

마우스를 올리면 얇은 점선과 작은 타임코드로 이동할 위치를 미리 보여준다. Hover만으로 영상 위치를 바꾸지 않는다. 시간 눈금에 초점이 있을 때 좌우 방향키는 한 프레임, Shift는 한 초, PageUp·PageDown은 5초, Home·End는 첫·마지막 프레임으로 이동한다. 재생 위치는 항상 마지막 재생 가능 프레임 안으로 제한한다.

드래그·미리보기는 프레임당 한 번 처리하고 같은 드래그에서 동일한 프레임 탐색은 생략한다. 잠금·버전 변경·창 전환·화면 크기 변경·스크롤 때 예약된 동작을 취소한다. Esc는 마지막으로 확인한 시점을 유지하며 탐색을 끝낸다. 키보드용 슬라이더는 눈금에만 부여해 마커·구간 버튼의 접근성을 유지한다.

## 얇은 펜의 크기 조절

화면에서 높이가 3px 이하인 펜은 좌우 손잡이만, 폭이 3px 이하인 펜은 상하 손잡이만 표시한다. 겹친 모서리 손잡이를 잡아 수평선·수직선이 옆으로 밀리는 일을 막고, 조절하지 않는 축의 원래 좌표와 작은 굴곡을 그대로 보존한다. 두 방향 모두 3px 이하이면 이동만 제공한다. 일반 펜과 박스·원의 8방향 조절, 선·화살표의 양 끝 조절은 유지한다.

## 영상 높이 조절과 디렉팅 집중 모드

데스크톱 미리보기는 하단 패널을 제외한 공간을 채운다. 영상의 비율은 유지하고 남는 면은 여백으로 처리한다. 영상과 하단 패널의 경계를 위아래로 끌어 일반 타임라인 높이를 조절한다. 기본 높이는 280px, 정상 조절 범위는 180–600px이며 창 높이에 맞춰 제한한다. 매우 낮은 창에서도 하단 제어를 위한 공간을 남긴다. 경계에서 ↑↓는 10px, Shift는 40px, Home·End는 최소·최대, Enter·더블클릭은 기본 높이, Esc는 드래그 취소다.

**최소화**는 타임라인을 48px 한 줄로 접는다. 재생·현재 시각, 얇은 탐색선·댓글 마커·선택 구간, 그림 도구·댓글 쓰기·펼치기를 남긴다. 썸네일·시간 눈금·구간 입력·상세 트랙은 접고, 그림 도구는 펜 아이콘으로 열어 사용한다. 펼치면 저장한 일반 높이로 돌아간다. 모드와 일반 높이를 이 브라우저에 기억하며, 창에 맞춘 임시 축소는 선호 높이를 덮어쓰지 않는다.

영상 요소와 오버레이 편집기는 모드 전환·크기 조절 중에도 유지한다. 구간·그림 좌표를 변경하지 않고, 영상 표시 크기에 맞춰 오버레이를 다시 맞춘다. 높이 드래그는 프레임당 한 번 처리하며 저장소에는 조절 완료 시 기록한다. 실제 화면의 크기·드래그·입력 반응 검수는 기존 브라우저 도구 접근 제한 때문에 아직 수행하지 못했다.

집중 모드에서는 새 썸네일 준비를 미루고, 이미 준비한 동일 영상의 썸네일은 펼칠 때 재사용한다. IN/OUT 드래그는 재생을 멈추고, 화면 갱신 주기마다 달라진 프레임만 반영한다. 놓은 마지막 위치는 즉시 반영하며, 창·패널 크기 변경이나 해당 시간축 스크롤·포커스 이탈로 좌표 기준이 달라지면 진행 중 드래그를 종료한다. 겹친 마커 목록에서 다른 단일 마커로 이동하면 목록을 닫는다. 최소화된 마커는 호버·선택 상태에서도 점 형태를 유지한다.
