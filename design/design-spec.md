# 작업 화면 디자인

2026-10-14 기준. 1인 데스크톱 도구의 우선순위는 **영상의 시점·구간을 지정하고, 장면 내용과 피드백을 남겨 문서로 전달하는 것**이다. 오른쪽 댓글 작성과 시간축 마커가 중심이며, 프로젝트·버전 및 보조 패널은 필요할 때 펼친다. 편집 실행과 AI 해석은 보조 기능이다. 모바일 설계는 후속 범위다.

사용자가 제공한 `AI 영상 편집 앱 — 시안 3종.html`의 **통합안 · 메인 리뷰 화면**과 **사이드바 1 · 큐 리스트형**을 이번 테마의 기준으로 적용한다. 특정 안을 사용자가 선택한 것은 아니므로, 댓글과 타임코드 중심이라는 요청에 맞춰 두 화면의 공통 시각 체계를 선택했다. 이전 `editor-concept.png` 등 다크·민트 PNG는 초기 아이디어이며 현재 디자인 기준이나 현재 화면 캡처가 아니다.

로컬 Pretendard를 유지한다. 댓글 본문은 14px, 입력은 13px, 타임코드와 일반 메타는 12px, 보조 안내는 11px로 구성한다. 시간은 시스템 고정폭 글꼴과 tabular 숫자를 사용한다. 패널·모달 모서리는 16px, 댓글·작성 카드 10~12px, 작은 버튼 8px이며 카드 내부 여백은 12px를 기본으로 한다. 1280·1440px 데스크톱에서 버튼과 툴바를 조밀하게 유지하되 댓글 본문은 줄이지 않는다.

첨부 시안과의 대응은 다음 다섯 곳에 집중한다.

1. 흰 상단 헤더와 중립 회색 작업 배경으로 영상과 댓글을 구분한다.
2. 오른쪽 댓글은 번호·고정폭 시점·본문 순서로 읽는다. 현재 선택은 파란 왼쪽 선과 옅은 배경으로 표시한다.
3. 재생 시간과 구간 핸들, 댓글 마커, 마크업 도구의 선택 상태에 같은 파랑을 쓴다.
4. 작성 영역은 흰 면과 명확한 입력 테두리를 쓰고, 저장을 주 행동으로 둔다. 상세 정보는 접을 수 있어야 한다.
5. 참고 이미지는 원본 비율을 유지하는 중립색 썸네일과 전체 보기로 확인한다. 파일명·삭제·이동은 보조 동작으로 정돈한다.

영상과 첨부 이미지에 테마 색을 덮지 않는다. 사용자가 그린 선·도형의 색도 유지한다. 색상과 타이포그래피는 `apps/web/src/theme.css`, 화면 그리드와 패널 접힘은 App과 기존 레이아웃 CSS에서 담당한다. 테마 파일을 모든 기본 CSS 다음에 불러온다.

현재 확인 범위는 첨부 HTML에서 추출한 실제 스타일 값과 구현 소스의 대응이다. 저장된 브라우저 접근 제한으로 최신 화면의 시각 검수는 아직 완료하지 못했다. 실제 영상 시간·진행 상태를 사용하며, 작업 완료 상태나 AI 결과를 디자인용으로 꾸며 넣지 않는다.

## 기본 정보의 노출

우측 댓글 작성창은 항상 표시한다. 타임코드, 선택 구간, 그림 요약, 댓글 입력과 저장을 우선한다. 장면 설명·이미지·음성·메모 등은 닫힌 추가 옵션에 둔다. 그림 도구는 상시 표시하고 색·굵기·채움은 그림 스타일을 펼쳐 변경한다. 프로젝트 패널은 기본 접힘, 댓글 패널은 기본 펼침이며 양쪽 접기 버튼을 제공한다. 현재 시점으로 시작해 필요할 때 구간을 지정하고, ×/구간 해제로 현재 시점에 돌아간다.
