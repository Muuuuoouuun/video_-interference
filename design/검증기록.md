# 데스크톱 앱 초안 검증

> 아래 기록은 초기 편집 앱 단계의 검증 이력이다. 최신 시간별 피드백 프로토타입과 새 그림 도구의 화면 검수 결과로 해석하지 않는다. 현재 자동·native 검증과 남은 화면 조건은 [완료감사](../docs/완료감사.md)와 [피드백프로토타입](../docs/피드백프로토타입.md)을 따른다.

작업 폴더는 `/Volumes/OneTouch/video_interference`이다. 모바일은 후속 범위다.

## 기능 검증

`npm run build`와 `npm test`가 외장 디스크 위치에서 통과했다. 실제 FFmpeg와 localhost API를 사용하는 12개 테스트로 컷, 구간 유지, 배속, 한글 자막, 정적 이미지, 음량, 누적 버전의 원본 매핑, 승인 보호, 첫 파일 가져오기와 맥락 프레임을 확인했다.

Codex 인앱 브라우저에서 요청 해석 값 수정, 수정 후 승인 해제, 승인한 두 작업 실행, 새 버전 생성, 비교, 드로잉 저장과 메모 비실행을 확인했다. 개발 서버를 이동한 뒤 기존 버전 목록이 유지되는 것도 확인했다. 음성 녹음의 실제 마이크 권한과 Claude API 호출은 검증하지 않았다.

샘플의 5~9초를 2배속으로 만들고 9~12초에 자막을 추가했다. 결과는 17.13초에서 15.13초로 줄었고, 비교 시 수정본 7.56초와 원본 9.56초가 같은 장면을 가리켰다.

## 디자인 비교

ImageGen 내장 도구로 만든 `editor-concept.png`와 브라우저 캡처를 직접 열어 비교했다. 기준 프롬프트는 한국어 1인용 영상 요청 에디터, 어두운 중립 배경과 민트 강조, 버전 레일·플레이어·시간축·요청 패널, 승인 버튼과 실제 ClassIn 영상이다.

| 항목 | 기준과 확인 내용 |
|---|---|
| 화면 구조 | 왼쪽 버전 기록, 중앙 16대9 플레이어·시간축, 오른쪽 요청 패널 |
| 색상 | 어두운 중립 배경, 밝은 글자, 민트 선택·승인 강조 |
| 글자 | 로컬 Pretendard, 요청과 해석의 구분, 큰 화면 한국어 글자 크기 보완 |
| 영상 | 실제 재생 영상 사용, 영상 위에 별도 색상 오버레이 없음 |
| 도구 | 윤곽선 아이콘, 인·아웃 핸들, 위치 메모, 보기 배속 구분 |
| 버튼 | 카드 안 승인·수정, 상단 승인한 요청 실행 |

컨셉과 같은 1586×992 데스크톱 크기를 확인했다. 최종 확인 시 가로·세로 페이지 넘침 없이 footer와 composer가 화면 안에 들어왔다. 현재 브라우저 크기에서도 기존 편집 흐름을 검증했다.

파일명에 따른 프로젝트 이름, 실제 영상의 프레임·길이, 승인 후 적용 상태, 추가된 메모는 컨셉의 샘플 내용과 다른 실제 실행 상태다. 기능상 비교·다운로드, 승인 취소, 드로잉 되돌리기와 메모 비실행 표시를 추가했다. 정밀 원본 PTS 대응, 댓글 스레드, 스타일 복제와 자동 전사는 후속이다.

마지막 브라우저 재확인은 접근 승인이 거절되어 중단했다. `editor-draft.png`는 그 전에 확인한 안정된 버전 비교 실행 예시이며, 최종 스타일 수정 이후의 새 캡처라고 주장하지 않는다.
